# 📊 Sales Data Analysis & Dashboard

A data analytics project focused on analyzing sales data to identify **business trends, customer behavior, product performance, and regional insights**.

## 🚀 Features

* Data cleaning and preprocessing using Python & Pandas
* SQL-based sales and customer analysis
* Identification of product and regional trends
* Interactive Power BI and Tableau dashboards
* Visualization of key business KPIs and sales performance

## 🛠️ Technologies

**Python | Pandas | SQL | Power BI | Tableau**

## 📈 Key Insights

* Sales and revenue trends
* Top-performing products
* Customer purchasing behavior
* Regional sales performance
* Business KPI analysis

## 🎯 Objective

To transform raw sales data into meaningful insights and interactive visualizations that support **data-driven business decisions**.
